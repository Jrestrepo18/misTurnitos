# Cambios de Mis turnitos 1.1

- El calendario muestra las iniciales de turno reconocidas: D, C, P y N.
- El símbolo `/` se interpreta como P (Posturno).
- Códigos alfanuméricos que empiezan por D, C, P o N se guardan como zonas/códigos y no se confunden con turnos.
- Al tocar un día, se muestra el turno, la zona/código completo y el valor original de la celda cuando hay zona.
- Se mantiene compatibilidad de lectura con calendarios guardados por la versión anterior.

Después de abrir esta versión, pulsa **Actualizar** o vuelve a importar el Excel una vez para procesar el cuadro con las nuevas reglas.
