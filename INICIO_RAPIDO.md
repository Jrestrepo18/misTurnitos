# Mis turnitos — inicio rápido

## Ejecutar en Windows

1. Extrae el ZIP.
2. Abre la carpeta `turnitos-pwa`.
3. Escribe `cmd` en la barra de direcciones del Explorador y presiona Enter.
4. Ejecuta:

```cmd
npm install
npm run dev
```

5. Abre la dirección local que muestra Vite (normalmente `http://localhost:5173/`).

## Novedad de la versión 1.3

Al abrir la aplicación, el calendario queda en el mes actual y el día de hoy aparece seleccionado y resaltado. Si se actualiza el enlace, se importa otro Excel o se cambia de auxiliar, la aplicación mantiene esa regla.
