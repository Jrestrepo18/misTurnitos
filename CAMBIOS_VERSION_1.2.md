# Cambios de Mis turnitos 1.2

- Los códigos de zona que comienzan por D, C, P o N también aportan esa inicial como turno al calendario.
- El código completo se conserva en el detalle del día: `P123A` muestra P en el calendario y `P123A` en zona/código.
- Aplica de igual forma a códigos como `C04`, `D-ZONA1` y `N_02`.
- El símbolo `/` continúa representando P (Posturno).

Después de abrir esta versión, pulsa **Actualizar** o vuelve a importar el Excel una vez para procesar los datos con esta regla.
